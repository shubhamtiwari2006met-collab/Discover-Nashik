# Global Project Rule — Explicit Consent for Git Commits & Pushes

1. **NEVER automatically commit or push code changes to GitHub.**
2. **Local Edits Only:** Freely edit, add, or debug local code files when requested by the user. Keep all changes in the local working directory.
3. **Wait for Explicit Instruction:** Only create commits or push to GitHub when the user explicitly requests it (e.g., "Push to GitHub", "Commit and push").
4. **Workflow Sequence:**
   `EDIT LOCALLY → FINISH & VERIFY WORK → WAIT FOR EXPLICIT PUSH COMMAND → THEN COMMIT/PUSH`
